🎮 SOBRE EL PROYECTO

Space Survival 2D es un juego de supervivencia espacial donde debes enfrentar hordas interminables de zombies espaciales. Con gráficos estilo arcade y mecánicas clásicas, este juego pone a prueba tus reflejos y estrategia.

Desarrollado con tecnologías web modernas, el juego cuenta con un sistema de rankings global donde puedes competir con jugadores de todo el mundo y subir en la tabla de posiciones.

Tecnologías utilizadas:

TypeScript HTML5 Canvas Python SQLite
